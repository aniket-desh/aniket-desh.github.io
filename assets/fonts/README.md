# Preview fonts

These unmodified fonts are bundled so social cards render without network access
or system-font dependencies. The site already uses these families.

- `AlegreyaSC-Regular.ttf`: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/alegreyasc), heading font.
- `Alegreya.ttf`: [Google Fonts source](https://github.com/google/fonts/tree/main/ofl/alegreya), original `Alegreya[wght].ttf`, regular body font.

Both are by The Alegreya Project Authors and distributed under the SIL Open
Font License 1.1. The accompanying `OFL-*.txt` files contain the licenses.
