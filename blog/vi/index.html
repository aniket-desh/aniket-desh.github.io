I. The Duality of Surprise

When we say that we want to make a language model smarter, what change are we asking for? A lower pretraining loss, a higher benchmark score, and a new skill can all look like progress from the outside, but they need not describe the same change inside the model. It can improve because it has stored more cases, because the test has become familiar, or because it has found a rule that makes many cases instances of the same problem. Only the last kind of improvement changes how much the model must learn the next time around.

This is an effective-reductionist question. Intelligence belongs to our description of an agent, while a neural network is implemented as arrays of numbers undergoing physical computation. The parameters are too low-level to explain the property, and the benchmark score is too high-level to locate it. We need an intermediate quantity that can be measured in the mechanism and still tells us something about what the system has learned. For a predictive model, information gives us one such bridge.

A language model repeatedly turns a history \(x_{<t}\) into a distribution over what might come next. If it assigns probability \(q(x_t\mid x_{<t})\) to the token that arrives, an ideal code spends \[ \ell_t=-\log_2 q(x_t\mid x_{<t}) \] bits to record it. A probability of \(1/2\) costs one bit; a probability of \(1/256\) costs eight. Across a sequence, \[ L_q(x_{1:T}) = -\sum_{t=1}^{T}\log_2 q(x_t\mid x_{<t}) = -\log_2 q(x_{1:T}). \] Surprise, predictive loss, and description length are the same bill written in different units. Arithmetic coding can turn the model's probabilities into a bitstream approaching this length, while the lengths of any uniquely decodable code induce a corresponding probability distribution.1

This is a duality between prediction and coding, not a definition of intelligence. A compressor can absorb regularities that never support planning, intervention, or learning in a new domain. It can also predict a dataset by storing the dataset. An honest account must charge for the description of the predictor as well as the data left unexplained. The regularities worth calling intelligent are the ones that cost less to represent than they save on cases the system has not seen.2

That qualification moves the question inside the model. Two networks can make the same predictions on their training examples while using descriptions of very different lengths. One can assign a separate mechanism to every case. The other can represent a relation once and reuse it. Their losses agree until the world asks for a new combination, at which point the difference between memory and structure becomes visible.

II. Seven Things, One Rule

Consider the days of the week. A system can learn seven unrelated successor functions: \[ f_{\mathrm{Mon}}\mapsto\mathrm{Tue}, \qquad f_{\mathrm{Tue}}\mapsto\mathrm{Wed}, \qquad \ldots \] Nothing in this representation says that the seven transitions are versions of one operation. A different system can assign every day a phase \(k\in\mathbb Z_7\) and learn \[ f(k,m)=k+m\pmod 7. \] The first program stores a table. The second stores a coordinate system and a rule. Both preserve which day is which, but the second can answer a question such as “three days after Thursday” without having stored that pair as a separate fact.

Generalization here is not seven concepts collapsing into one point. Such a collapse would destroy the information required to distinguish Monday from Thursday. It is seven arbitrary symbols becoming seven states of one latent variable. What gets compressed is their relational description: \[ \underbrace{\text{many unrelated transitions}}_{\text{lookup table}} \quad\longrightarrow\quad \underbrace{\text{one generator applied repeatedly}}_{\text{shared rule}}. \] The entropy of the answer need not fall. The length of the program that relates the answers does.

A cyclic representation makes this compression visible. At checkpoint \(t\), suppose a state \(k\) in context \(c\) has activation \[ h_t(k,c) = b_t + A_t \begin{bmatrix} \cos(2\pi k/7) \\ \sin(2\pi k/7) \end{bmatrix} + r_t(k,c). \] The matrix \(A_t\) embeds a common phase into activation space, while \(r_t\) contains context, surface form, and whatever else the network superposes there. A single rotation \(R_t\) can now implement the successor relation: \[ R_t h_t(k,c)\simeq h_t(k+1,c), \qquad R_t^7\simeq I. \] Seven cases have become an orbit of one operation.

Weekdays are only the easiest picture. Months and clock positions are other cycles. A two-dimensional periodic grid requires two commuting generators. Binary attributes under XOR form a hypercube. Rotations and reflections form a dihedral system in which the operations no longer commute. Paths, trees, and broken cycles have boundaries or exceptions that prevent the same exact symmetry. If relational compression is a useful account of generalization, the geometry should follow the structure of the problem rather than our preference for circles.

This also explains why low dimensionality is the wrong definition of compression. A cyclic representation may use several Fourier harmonics, \[ h(k) = \sum_q a_q\cos(2\pi qk/7) + b_q\sin(2\pi qk/7), \] and still be exactly equivariant to the same shift. The resulting loop may be rippled and high-rank while the underlying rule remains short. What matters is whether the representation admits a common action, not whether its first two principal components draw a pretty circle.

III. Geometry Is Not Generalization

Circular weekday and month features already appear in trained language models. Engels, Michaud, and collaborators found these structures in GPT-2, Mistral, and Llama-family models, then used interventions to show that the circles participate in calendar arithmetic.3 Goodfire later traced smooth activation and behavior manifolds in Llama 3.1 8B, and found a more general geometric addition mechanism spanning ordinary arithmetic and cyclic concepts.4 These experiments show that a trained model can use a nonlinear feature as a computational object.

They do not show that the circle appeared when the model learned to generalize. A cyclic geometry can be the passive consequence of cyclic statistics. If the relationship between two states depends mostly on their separation, their co-occurrence matrix is approximately circulant. Circulant matrices have Fourier eigenvectors, whose first sine and cosine pair already traces a circle. Recent work derives this mechanism for calendar concepts and finds that it persists across embedding models and language models.5

The distinction is developmental. A model may first organize observations according to a symmetry in its data, later learn an operation that acts on that organization, and later still remove the machinery that memorized individual cases. The representation, the reusable computation, the held-out behavior, and the final cleanup can occur at different times. A static activation plot cannot tell us which event we are looking at.

Park and collaborators have come closest to watching arbitrary concepts acquire a new geometry. They assigned familiar words to nodes of rings, grids, and other graphs, then supplied a fixed language model with increasingly long traces from those graphs. Its activations reorganized toward the context-specified structure shortly before its answers improved. When a new ordering of weekdays conflicted with the calendar learned during pretraining, both rings remained present in different subspaces.6 A concept can acquire a relational role without erasing everything it previously meant.

Grokking supplies the training-time analogue. Small transformers trained on modular addition often memorize their observed table long before they generalize to its missing entries. Nanda and collaborators reverse-engineered a Fourier algorithm that gradually forms underneath this apparently sudden behavioral transition, then watched memorizing components disappear afterward.7 The result suggests a sharper account of learning: the model gets better when an expensive collection of exceptions is displaced by a reusable computation, even if its training loss had already reached zero.

IV. What a Rule Looks Like from the Inside

The compression claim becomes stronger here. A model has not compressed the weekdays merely because Monday through Sunday occupy nearby points. It has compressed them when the same internal transformation explains all seven successor relations. In the language of two-part codes, memorizing seven arrows pays for seven separate pieces of program, while learning a state variable and one rotation pays once and reuses the result.2 The circle matters only insofar as it makes that reuse possible.

Before this reorganization, the model can treat each surface form in each context as its own route to an answer. Afterward, those surface forms become instances of seven states, and the seven states become positions on one orbit. The answer space has not become smaller. The causal vocabulary has. Seven local explanations have been replaced by one generator plus a coordinate that says where the system currently is.

This is the sense in which generalization begins to look like intelligence. A lookup table can answer an old question. A relational representation can answer a new one because what it learned from one case changes how it treats the others. The more general learner is the one that discovers which distinctions can be factored away, which must be preserved, and which operation can be spent again on an unseen case. Its advantage is measured by how quickly experience becomes reusable structure, not by how many answers it can eventually memorize.

Geometry gives this act of reduction a visible form. If seven clouds of context-dependent activations gradually become seven positions on one orbit, we are watching the model invent a variable. A periodic grid should instead acquire two commuting directions, an XOR problem a hypercube, and a problem with reflections a geometry whose operations do not commute. Each shape is an internal grammar for what transformations are possible. A circle with no reusable shift is decoration; a warped, high-dimensional orbit on which one shift acts reliably is compression.

From far away, language-model training can still look smooth. Mean loss averages over an enormous number of predictions, so many local reorganizations can disappear into one clean scaling curve. Michaud's quanta picture asks whether that smoothness is built from smaller changes in which mechanisms and pieces of knowledge the model has acquired.11 Following geometry through training adds a more precise question: when a capability appears, did a new relational variable form, did an existing one become usable, or did the model merely learn to read out structure that was already there?

V. Measuring Reuse

To call this compression, we need a quantity that cannot be won by choosing a flattering projection. The natural object is not the picture but the relations among the states. Let \(H_t\in\mathbb R^{n\times d}\) contain centered activation centroids for \(n\) states at checkpoint \(t\), averaged across surface forms and contexts, and let \[ G_t=H_tH_t^\top \] be their Gram matrix. \(G_t\) forgets the arbitrary orientation of activation space while retaining every pairwise inner product.

For a cycle, let \(P\) shift every state by one. If the representation has recognized one common orbit, shifting both arguments should preserve every inner product. We can project the Gram matrix onto the nearest cyclically invariant one, \[ \overline G_t = \frac{1}{n} \sum_{m=0}^{n-1} P^mG_tP^{-m}, \] and define the symmetry defect \[ \Delta_{\mathrm{cyc}}(t) = \frac{\lVert G_t-\overline G_t\rVert_F} {\lVert G_t\rVert_F}. \] This defect is computed in the full representation and becomes small when relative geometry depends only on cyclic separation. It asks whether seven concepts have become positions in one system, without demanding that the system look circular in two principal components.

Symmetry is still only evidence that the representation knows which states belong together. Statistics alone can produce a ring, and even a regular simplex has abundant symmetry. The stronger question is whether one operation can be learned on some states and contexts, then reused on others. Fit \(R_t(g)\) on part of the orbit and measure both its held-out equivariance and whether repeated application closes the cycle: \[ \epsilon_{\mathrm{eq}}(t) = \frac{\lVert R_t(g)h_t(k)-h_t(gk)\rVert} {\lVert h_t(gk)\rVert}, \qquad \epsilon_{\mathrm{close}}(t) = \frac{\lVert R_t(g)^n-I\rVert_F}{\sqrt d}. \] A reusable rule reduces both errors without erasing which state is which. This is the geometric analogue of a program bit paying for itself across many predictions.

Causality closes the argument. Replace an activation \(h_t(k)\) with \(R_t(g)h_t(k)\) where the operator is most coherent. If the model's output moves from \(k\) toward \(gk\), the geometry is part of the computation rather than a description imposed afterward. The relevant progress measure is therefore the alignment of four traces over training: \[ \text{held-out behavior}, \qquad \text{full-space symmetry}, \qquad \text{operator reuse}, \qquad \text{causal motion}. \] Their relative timing tells us what kind of event generalization was. The measure is not a universal intelligence score. It is a microscope for one act of intelligence: the moment many cases become one cause.

VI. Experiments

The first anchor experiment is modular addition of order 113. Four one-layer transformers saw the same 30 percent of the operation table and were trained with strong weight decay. Every model memorized its observed entries while remaining at chance on the rest. Held-out accuracy then crossed 90 percent at steps 26,750, 27,000, 31,250, and 64,750.

At initialization, the median embedding distributed its energy across 55.8 effective Fourier modes and had a cyclic defect of 0.68. One thousand steps after each run crossed 90 percent held-out accuracy, those medians were 18.5 modes and 0.33. The movement began before the behavioral transition, accelerated through it, and continued after accuracy had saturated. The model did not discover one privileged circle. It concentrated a diffuse collection of case-specific directions into a smaller set of harmonics on which one shift could act.

The transition was not perfectly final. Three seeds remained at perfect held-out accuracy through step 150,000, while one later fell to roughly 70 percent under the same strong weight decay. Nor was the cleanest geometry found at the output of the transformer block. It appeared in the state embedding and became messier downstream. Both details matter: a progress measure should follow the representation where the shared rule is written, and generalization can be lost when continued optimization damages that representation.

A second, noisier check follows natural concepts through Pythia's public pretraining checkpoints.10 In the 1B model, the fraction of weekday activation energy in the first cyclic harmonic rose from 0.34 at initialization to 0.57 by step 4,000, while average probability on the correct successor among weekday candidates moved only from 0.15 to 0.20. It reached 0.25 much later. The 410M model showed the same ordering. This is consistent with a statistical geometry forming before the model can reliably use it, but it is not causal evidence. Prompt completions are noisy, and a harmonic can be present without carrying the computation.

The remaining runs ask whether this story survives outside modular addition. They replace one name per state with sixteen arbitrary aliases, then repeat the protocol on larger cycles, tori, XOR, rotations with reflections, bounded paths, trees, broken cycles, and random-permutation controls. Those experiments will determine whether the pattern is relational compression or merely the familiar Fourier signature of modular arithmetic.
